# Nano Banana Studio

이미지를 분석해 재구성용 프롬프트를 추출하고, 필요하면 Gemini 이미지 모델로 결과를 생성하는 로컬 앱입니다.

## 세 가지 화면

- `http://127.0.0.1:3000/` — 기존 분석 유지 버전. 기존 시스템 프롬프트, JSON 스키마, 1회 분석 흐름을 보존합니다.
- `http://127.0.0.1:3000/harness.html` — 새 분석 하네스. 증거 수집 → 교차 비평 → 최종 합성을 수행합니다.
- `http://127.0.0.1:3000/compare.html` — 같은 이미지와 설정으로 두 분석을 A/B 비교합니다.

Agentic Vision(코드 기반 정밀검사)은 세 화면에서 기본적으로 꺼져 있습니다. 켜더라도 모델이 필요할 때만 사용하며, 하네스 자체는 이 기능 없이 완결됩니다.

## 실행

1. Node.js를 설치합니다.
2. 처음 한 번 `npm install`을 실행합니다.
3. `npm run dev`를 실행하거나 원하는 `실행하기*.bat` 파일을 엽니다.
4. 설정에서 Gemini API 키를 입력하고 모델 목록을 새로고침합니다.

API 키는 소스, `.env`, 브라우저 저장소, 히스토리 및 ZIP 내보내기에 저장되지 않고 앱이 실행되는 동안 메모리에만 유지됩니다. 기존 분석·새 하네스·비교 화면을 오가도 유지되며 앱을 닫거나 새로고침하면 사라집니다.

## 히스토리

- 원본과 생성 이미지는 OPFS에 저장합니다.
- 분석, 프롬프트, 설정, 검색 메타데이터와 썸네일은 IndexedDB에 저장합니다.
- 임의 개수 제한이나 자동 삭제가 없습니다. 실제 한도는 브라우저가 이 사이트에 배정한 저장 공간입니다.
- 사이드바에서 지속 저장 권한을 요청하고 사용량을 확인할 수 있습니다.
- ZIP 내보내기는 지원 브라우저에서 파일로 직접 스트리밍합니다.
- 기존 v1 히스토리는 원본을 지우지 않고 새 구조로 복사합니다.
- 비교 분석에서 성공한 기존 분석과 새 하네스 결과도 각각 히스토리에 자동 저장합니다. 한쪽이 실패해도 성공한 쪽 결과는 유지합니다.

## 분석 실행 리포트

- 선택 모델과 API 응답 모델, Agentic Vision 선택·실제 사용 상태, 정밀검사 횟수·영역·결과, 토큰, 소요 시간, 실패·거절 사유를 기록합니다.
- 전체 비용과 Agentic Vision 직접 귀속 비용은 실제 토큰과 2026-07-21 공식 Standard 유료 티어 단가로 계산한 USD 추정액입니다. 무료 티어·캐시·계약 단가는 반영하지 않습니다.
- 리포트는 작업 공간과 히스토리에서 보이며, 개별 `.md` 저장과 전체 ZIP의 `report.md` / `report.json` 내보내기를 지원합니다.
